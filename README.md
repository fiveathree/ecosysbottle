# 生態瓶實驗室 · Eco Jar Lab

3D ecosystem-jar simulator · 3D 生態瓶模擬器（中文／English）

- 水族、雨林、水陸共生三種模式，切換時保留原有嘅嘢；最多 3 個獨立命名嘅瓶
- 每樣生物有自己嘅參數（產氧、耗氧、食量、幾耐去一次廁所、溫度／濕度範圍、繁殖），可以改名
- 由零開始造景：細沙、碎石、泥土土坡、石頭、假山、假橋、沉木，可以直接拖動
- 設備：氧氣泵、過濾、加熱棒、換水、噴霧、加熱燈；瓶形狀同材質
- 地區氣候（香港、亞馬遜、婆羅洲、撒哈拉、大堡礁、地中海、京都、貝加爾湖）同天氣（雨、雷暴、霧、沙塵暴、雪）
- 平衡分析、3 日預測、一鍵平衡；真實嘅瓶只會俾建議
- 分析現有水缸：分開已知數據、觀察、規則推斷同模擬推測

## 開發

源碼喺 `src/`，執行 `python3 build.py` 會砌出 `index.html`（GitHub Pages）同 `dist/artifact.html`。
